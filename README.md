## About Calculus Tools

Calculus Tools is an HTML project that runs in the browser and centers on visualizing solids of revolution. Users can examine what happens to a region when it is rotated and then compare the resulting shape across the disk, washer, and shell methods.

The project fits learning, instruction, and review of fundamental calculus ideas through a visual approach. Because all three methods live in a single interface, it becomes easier to tie formulas back to geometry and to observe how different techniques describe the same volume problem.

---

## Features

- Produces solids of revolution for calculus visualization
- Includes the disk method for setting up and interpreting volume
- Includes the washer method for rotation problems with hollow regions
- Includes the shell method as an alternative way to model volume
- Implemented in HTML, so it runs on the web
- Built for comparing methods side by side in one interface
- Well suited to classroom demonstrations and self-paced study
